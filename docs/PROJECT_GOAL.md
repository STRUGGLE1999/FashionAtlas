# FashionAtlas Project Goal

## North Star
让时尚新手在 5 分钟内完成一次可信审美启动。

具体来说：用户带着一个模糊兴趣或具体场景进入 FashionAtlas，例如“我想了解 Archive Fashion”“我想看懂巴黎时装周”“我想提升日常通勤穿搭”，能够快速获得一组书籍、影片、秀场、杂志或趋势内容推荐，并收藏至少 1 个可继续学习/穿搭实践的灵感条目。

## Why This Goal
FashionAtlas 的关键价值不是“收录最多资源”，而是把分散、专业、版权边界复杂的全球时尚资料和中国日常趋势组织成新手可以开始行动的中文策展入口。

这个目标同时约束了三个产品判断：
- 不为了数量牺牲可信度。
- 不让 AI 变成泛聊天，而是回到推荐清单、趋势内容、资源库和下一步行动。
- 不托管盗版资料，长期保持可公开运营。
- 不把趋势内容做成导购，不做价格分析、预算分层或替代单品推荐。

## MVP Requirements
- 首页必须明确传达“学习型资料站 60% + 日常趋势资讯 40%”的产品定位。
- 用户可以搜索或筛选至少 100 条资源。
- 每条资源都有详情页、来源链接、学习价值和版权/访问说明。
- 推荐清单覆盖书籍、影片、杂志、秀场，并说明适合谁、怎么看、在哪里合法获取。
- 趋势栏目包含年度/月度/每周趋势观察，并列出来源依据和编辑判断。
- AI 助手可以把模糊问题转成学习路径、推荐清单、趋势参考和推荐资源。
- 项目复盘材料能向面试官解释用户痛点、MVP 取舍、AI 设计和指标。

## Metrics
- 首次任务完成率：5 分钟内进入 1 个推荐清单/趋势页并收藏 1 个灵感条目。
- 推荐清单采纳率：用户是否进入详情、收藏或继续浏览相关内容。
- 趋势内容留存率：用户是否阅读周/月趋势并收藏穿搭灵感。
- AI 采纳率：AI 输出后点击推荐资源或继续浏览路径。
- 路径深度：同一路径连续访问资源数。
- 回访/收藏意愿：用户是否愿意把网站当作长期资料入口。

## Current Progress
- 已实现 112 条策展资源。
- 已实现 8 个推荐清单、4 期趋势内容、8 个频道、6 条学习路径、20 个风格词条、30 场秀场路径和 50 本书。
- 已实现资源库搜索、筛选、详情页和官方/合法入口。
- 已实现 AI 助手，支持基于推荐清单、趋势和资源库回答，支持真实 API 和本地模拟兜底。
- 已实现灵感板收藏推荐清单、趋势、资源、风格、书籍和秀场，并支持导出 Markdown。
- 已实现项目复盘、部署说明、面试讲述脚本和上线清单。
